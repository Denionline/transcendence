# Seed fixtures

The demo media `make seed` plants in the upload volume. Committed on purpose:
on a machine that has just cloned this repository the bytes can only come from
the volume (empty by definition), the network (excluded — the app must seed
offline) or the repository. Only one of those is left.

Everything here is **generated by `generate.py`**, never downloaded: no
third-party media, no likenesses, no licence questions. Regenerate with

```sh
python3 prisma/seed-assets/generate.py    # needs Pillow and ffmpeg
```

Two rules for anyone adding a fixture:

- **Keep the directory under 1 MB.** Git keeps every blob it has ever seen, so
  an oversized demo video cannot be un-committed — `make oblivion` will not
  reclaim it. It is ~150 KB today.
- **The MIME must be in `src/lib/file-limits.ts`.** `seedFiles()` derives the
  `FileType` and extension from that table, so a fixture the API would refuse
  to accept fails the seed loudly rather than seeding demo data that could
  never have been uploaded.

The `File` ids that point at these files are hardcoded in `seed-data.json` —
that is what makes re-seeding idempotent, and it is why seeded ids, unlike
uploaded ones, are public. See `docs/mad/20260819-file-uploads.md`.
